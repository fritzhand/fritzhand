## 👋 About Me

*Catalyzing individuals and organizations to create positive impact.*

I believe the world gets better when more people have the tools, support, and confidence to build things.

So I build things. And I help others build things. And sometimes I build the things that help others build things.

The form keeps changing — startup incubators, artisan enterprises, peace-tech platforms, AI tools. The intention doesn't.

- 🌴 &nbsp;**New chapter:** I'm **VP of Platform & Member Engagement at [Embarc Collective](https://embarccollective.com)**, the startup hub in Downtown Tampa — building the programs, partnerships, and operating infrastructure that help Florida founders get from idea to scale.
- 🗺️ &nbsp;Currently building the **[Florida Startup Ecosystem Map](https://map.embarccollective.com)** — an independent, source-linked map of who does what and where across Florida. *(more below ↓)*
- 🏛️ &nbsp;Previously **CEO of VentureStudio**, the innovation & incubation platform at **Ahmedabad University** in India — programs like **MentorManthan**, **BioSangam**, **BIPASS**, and the **VentureStudio Fellowship**. Before that, **Director of Startup Services at Alloy Growth Lab** in Greater Cincinnati.
- 🤖 &nbsp;**AI optimist** — I build AI tools and intelligence platforms for founders, universities, and ecosystems: [contxtmd](https://contxtmd.com), [EduStrat AI](https://edustratai.com), [GazetteIQ](https://gazetteiq.com), [MentorManthan](https://mentormanthan.in), and more.
- 🧵 &nbsp;Co-founded **Bagru Textiles** — now **[Studio Bagru](https://studiobagru.com)** — fifteen years connecting Rajasthan's hand block printing artisans to global markets.
- 🕊️ &nbsp;Founded **[PeaceRise](https://peacerise.app)** — a peace-tech platform that grew to 200+ partners across 26 countries.
- 💬 &nbsp;Ask me about **ecosystem design, mentor networks, university innovation, social enterprise, and building real products with AI**.
- 📍 &nbsp;**Tampa Bay, Florida** — via Ahmedabad, Bagru, Cincinnati, and everywhere in between.

## 🗺️ Florida Startup Ecosystem Map

<a href="https://map.embarccollective.com">
  <img src="https://img.shields.io/badge/Live-map.embarccollective.com-F15A29?style=for-the-badge&logo=vercel&logoColor=white" alt="Florida Startup Ecosystem Map" />
</a>

**Florida's startup ecosystem is real, but it's scattered across a dozen metros with no single directory of who does what and where.** So I'm building one.

An independent, **source-linked** map of the accelerators, incubators, investors, universities, economic-development organizations, programs, and capital that make up the state — organized by **sector**, **region**, and **stage**.

<div align="center">

| | | |
|:--:|:--:|:--:|
| **224** | **13** | **19** |
| organizations mapped | regions | sectors |
| **308** | **100%** | **0** |
| cited sources | orgs with a source | invented facts |

</div>

The trust anchor is mechanical, not aspirational: **the build refuses to publish an organization that has no cited source URL.** Unknown fields are left blank rather than guessed. A green build is the acceptance gate for every new record.

**What's in it**

| Surface | What it does |
|---|---|
| **Directory** | Every organization, filterable by sector · region · stage · type |
| **Choropleth map** | The whole state by region, with density and hub detail |
| **Walkable map** | A full-screen, explorable Florida you actually move through |
| **"Why Florida"** | A sourced economics argument — also a paginated A4 report and PDF, where every figure and footnote is read out of the data at build time |
| **Start here** | A decision-finder wizard that routes a founder to the right handful of orgs |
| **The Glaring Gap** | Where the ecosystem's capital and support thin out — and who's working on it |

It foregrounds the four **[Ambition Accelerated](https://ambitionaccelerated.com/)** sectors — FinTech (West Palm Beach), Dual-Use/Defense (Miami), HealthTech (Tampa Bay), Resilience (Southwest Florida) — while serving anyone building in Florida.

<sub>Built as a **zero-dependency** static site: one Node script turns JSON + a CSS skin into the whole thing. The report's PDF, the social cards, and a 30-second Remotion reel all read their figures from the same data — so a revised number flows everywhere, and a deleted source fails the render instead of freezing a stale figure into a PNG.</sub>

## 🔓 Open Source

Ecosystem building runs on knowledge that usually stays locked inside incubators. I open-source mine — playbooks, tools, and infrastructure for founders and the people who support them:

| Project | What it is |
|---|---|
| **[startup-stack](https://github.com/fritzhand/startup-stack)** | The documents every startup should have, compiled into an AI-readable knowledge base — templates, prompts, and weekly recap rituals |
| **[open-innovation-stack](https://github.com/fritzhand/open-innovation-stack)** | Shared infrastructure proposal connecting founders, incubators, universities, mentors, and funders |
| **[site2deck](https://github.com/fritzhand/site2deck)** | Turns any company website into a branded, offline HTML slide deck — design tokens sampled automatically |
| **[geo-landing-page](https://github.com/fritzhand/geo-landing-page)** | Astro landing-page template optimized for search engines *and* AI crawlers |
| **[pressroom](https://github.com/fritzhand/pressroom)** | Turns organizational updates into newsletters and social content |
| **[ai-dev](https://github.com/fritzhand/ai-dev)** | Build a landing page. Build your app. Understand every step. A project-first course for people who aren't developers |

### 🇮🇳 Built in India, left open

Five years in Ahmedabad taught me how much of India's public record is technically public and practically unusable. These are attempts to fix that — all independent, all unofficial, all sourced:

| Project | What it is |
|---|---|
| **[startup-india-guide](https://github.com/fritzhand/startup-india-guide)** | An independent, source-linked guide to **69 central-government startup schemes**, with finder tools that route a founder to the ones they actually qualify for |
| **[open-india-law](https://github.com/fritzhand/open-india-law)** | Open, structured Indian primary law — **32.5M judgment chunks** from the Supreme Court and all 25 High Courts, 1.1M legislation provisions, and the scrapers that build it. CC BY 4.0 |
| **[open-ondc](https://github.com/fritzhand/open-ondc)** | An independent portal for India's Open Network for Digital Commerce — company info and open-source projects, sourced and cross-linked |

If something here is useful to you, a ⭐ helps other builders find it.
